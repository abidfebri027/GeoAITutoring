# Roadmap

## MVP

- Telegram bot as the student interface
- n8n workflow for the Socratic tutoring loop
- Supabase student profile, chat memory, and concept mastery
- tutor prompt with direct-answer prevention
- scoring evaluator and mastery update logic
- manual curriculum chunks for initial testing

## Version 1

- automatic embedding workflow
- retrieval connected to the main tutor workflow
- misconception taxonomy for disaster geography
- assessment question bank
- teacher dashboard for mastery and misconceptions
- progress summaries for teachers or parents

## Version 2

- RAGFlow ingestion for textbooks, PDFs, tables, and diagrams
- reranking for better retrieval quality
- citation display for teachers
- Indonesian and English tutoring modes
- spaced repetition reminders through Telegram
- classroom and group support

## Production

- prompt versioning and evaluation tests
- rate limiting and abuse controls
- privacy and retention policy
- backup and restore process
- cost, latency, and model-failure monitoring
- deployment runbook
